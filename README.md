# SneakerPlug 🏁

Welcome to SneakerPlug, a sleek and responsive React + Vite powered web application that showcases premium sneakers with style. This project combines clean UI, animated transitions, shopping cart functionality, and a smooth checkout experience — perfect for modern e-commerce.

## 🚀 Features

- Smooth product previews and detail pages
- Animated "Add to Cart" and "Checkout" interactions
- Sticky and responsive layout
- Fake payment form with success state
- Mobile-first design

## 🛠 Tech Stack

- React – For building interactive UIs
- Vite – Lightning-fast development and HMR
- Tailwind CSS – Utility-first styling
- Lucide Icons – Clean and lightweight icon set
- React Router – Client-side routing
- Context API – Global cart state management

### This is a demo project. Please don't enter real payment information.
